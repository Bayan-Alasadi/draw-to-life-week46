# Draw to Life — Week 46

This is a one-page interactive art site created for the creative programming assignment.

## How to open

Open the folder in Visual Studio Code, then right-click `index.html` and choose **Open with Live Server**. Internet connection is required to import PixiJS.

## What works

- Draw with a pen and five shades of blue.
- Change brush size, erase, undo, redo, clear.
- Press **Transform sketch** to create animated generative echoes and dots using PixiJS.
- Save a PNG image of the artwork.
- Responsive layout for phones and computers.

## Important

**Transform sketch is not an external AI image generator.** It uses generative drawing rules in PixiJS. If you want real AI image-to-image generation, it requires a separate supported AI API/backend and must be integrated later. Do not describe this version as producing AI-generated images.
